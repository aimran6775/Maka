# makapark.com

The static download site. `index.html` is the page; it is version-free and reads
`releases/download.json` at load, so a release changes only the files under `releases/`:

| File | Written by | Read by |
| --- | --- | --- |
| `releases/latest.json` | `scripts/release-site.mjs` | the app's updater (Tauri's static manifest: version, pub_date, platforms.darwin-aarch64 { url, signature }) |
| `releases/download.json` | `scripts/release-site.mjs` | `index.html` (version, date, the `.dmg`'s URL, size and SHA-256, notes) |
| `releases/Maka-<version>-aarch64.dmg` | the release build | people |
| `releases/Maka-<version>-aarch64.app.tar.gz` + `.sig` | the release build | the updater |
| `releases/SHA256SUMS` | `scripts/release-site.mjs` | people |

`scripts/release-site.mjs` assembles the whole site into `dist/site/` (this directory plus
the release files); `docs/RELEASE_RUNBOOK.md` says how to publish it. Nothing here is
generated by hand and nothing in `releases/` is committed (it is gitignored).
