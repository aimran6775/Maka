Install. Open the .dmg, drag Maka to Applications, open it. The app is signed with a Developer ID and notarized by Apple, so Gatekeeper opens it without a warning. On first run Maka asks where the crew works, for a Claude API key, for a local model in Ollama, and for the mission.

Verify the download. shasum -a 256 ~/Downloads/<file>.dmg must print the SHA-256 above.

Updates. Maka checks releases/latest.json on this site when it starts and offers an update from its menu bar item; updates are signed with Maka's own key and verified before they install.

What it is. One Node sidecar runs the agents; the park is the org chart and the permission model; every action with money or outside effect passes the Entrance Gate under a leash you set; the UI shows only what the agents proved. Maka never promises income: it shows what the crew did and what it cost.

Source: github.com/aimran6775/Maka (MIT). Modeled on the concept and architecture of StarNet (MIT, Andrew Sims) and built from scratch.
